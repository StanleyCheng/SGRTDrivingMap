# Live road conditions · 實時路況

**Feature note · 2026-09-22**

The server-hosted map now adds official live road-condition reports from LTA DataMall. These
overlays complement the camera inventory; they are not inferred traffic data and no location is
invented when an official report lacks coordinates.

## Four map layers, six official feeds

| Driver layer | LTA DataMall feed | Cache TTL | What is shown |
|---|---|---:|---|
| Traffic speed segments · 車速路段 | Traffic Speed Bands v4 | 5 min | Speed band and published minimum/maximum speed, using the feed's start and end coordinates. The resulting line is a **schematic endpoint segment**, not a full road geometry. |
| Live incidents · 實時事故 | Traffic Incidents | 2 min | Point incidents: accidents, breakdowns, obstructions, diversions and related traffic events. |
| Hazards · 路面警報 | PUB Flood Alerts | 3 min | Current flood alerts, mapped only when the published alert circle can be read as coordinates. |
| Hazards · 路面警報 | Faulty Traffic Lights | 2 min | Blackout/flashing-yellow reports. LTA supplies no coordinates, so the official records are listed/statused but unmapped. |
| Roadworks & openings · 道路工程及通車 | Approved Road Works | 24 h | Official road-name, time-window and agency report; unmapped because no site or work extent is published. |
| Roadworks & openings · 道路工程及通車 | Planned Road Openings | 24 h | Official road-name and opening schedule; unmapped because no site or extent geometry is published. |

Unmapped is intentional: a guessed pin or a whole-road highlight would be less truthful than an
official report without geometry. Each layer exposes both total and mapped counts so this
distinction remains visible.

## Server behaviour · 伺服器模式

`/api/road-conditions` aggregates all six credentialed feeds. The DataMall Account Key stays in
`DATAMALL_ACCOUNT_KEY` on the server and is never sent to the browser. Each feed is read through
DataMall's 500-record `$skip` pages, with at most 100 pages accepted to prevent an unbounded
response.

Fresh responses are retained in memory and `.cache` using the source TTLs above. A request after
expiry refreshes the source; if LTA is unavailable, a recent successful payload is served as
`stale` only within that feed's maximum stale age. With no usable cache, that source is reported
as unavailable; mixed source health is reported as `partial`. Public callers cannot bypass source
TTLs. The API response uses `Cache-Control: public, max-age=60, stale-while-revalidate=300` when
healthy and `no-store` when degraded.

## Static GitHub Pages behaviour · 靜態模式

GitHub Pages has no Node API route or protected credential store. In static mode the road-condition
layers are explicitly unavailable rather than making a credentialed request from the browser or
embedding `DATAMALL_ACCOUNT_KEY`. The static camera snapshot and keyless data.gov.sg traffic-image
feed continue to work; only these six live road-condition feeds require the server-hosted app.
